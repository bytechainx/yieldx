# yieldx 能力标准

**crate**：`yieldx` v0.1.0 | **source_id**：`yield_curve` | **角色**：收益率曲线 kernel 的 L0 值对象与批校验

> `kind = kernel` · `access_mode = none` · `authorization = not_applicable` ·
> `implementation_status = skeleton` · `production_decision = NO-GO`。
> 清单 COMPLETE ≠ ship；authorization ≠ Production Ready。
> 本文件是判定基准；`tests/sdd_spec.rs` 的 `// SPEC-MAP:` 与之逐节 1:1。

---

## 1. Kernel 义务与能力边界

- **本域是 kernel，不是 provider**：`kernel_owns` 只对 `L0ValueObjects` 与 `BatchValidation`
  返回 `true`；`HttpFetch` / `Authentication` / `Cache` / `Redistribution` 一律 `false`。
- **本库没有授权面**：`authorization = not_applicable`，因此不存在 `authz` 模块，
  也不导出任何授权类型或判定函数。
- **不得借 kernel 批 provider 授权**：`guard_provider_adapter_scope()` 恒返回
  `WriteAuthorityDenied`；32 个 provider 是**规划目录**（`PROVIDER_ADAPTERS_PLANNED = 32`，
  `PROVIDER_ADAPTERS_IMPLEMENTED = 0`），MUST NOT 据此授权。
- 零 HTTP 客户端、零异步运行时、零日期库、零凭据读取、零 `path` 依赖、零端点字面量。

## 2. 期限与曲线种类标准

- `YieldCurveTenor` 的标准期限共 11 个（`TENOR_CATALOG`），**变体声明顺序即到期月数递增顺序**，
  故派生 `Ord` 具有排序语义；`tenor_order_and_months_agree` 钉死「声明顺序 / `months()` / `Ord`
  三者一致」这一不变量。
- `YieldCurveTenor::parse` 只接受规范标签且**大小写敏感**（`10Y` 合法，`10y` 拒绝）；
  非规范期限（如 `4Y`）拒绝。
- `YieldCurveKind` 只有清单提到的**三态**：`Nominal` / `Real` / `Ois`（标签 `nominal` /
  `real` / `ois`）；`forward` 之类的第四态一律拒绝。
- `YieldCurveConvention` 的取值域清单**未钉死**：本层只校验「非空、无前后空白、无控制字符、
  不超过 64 字符」，MUST NOT 虚构惯例全集，也 MUST NOT 据此做任何计算。
- `Date` / `Period`：严格 ISO；日期须校验月范围、日范围与闰年；拒绝 `2026-2-3`、
  `2026/08/15` 与带时间部分者。不引入日期库。

## 3. 曲线点身份与规范键标准

- 身份 = `source + series + currency + valuation_date + maturity + curve_kind + vintage` 七元组。
- 四个字符串维度统一为 `YieldCurveCode`（非空、无前后空白、无控制字符、不超过 64 字符）；
  本层只校验「是一个可区分的非空身份」，**不做**来源或币种白名单。
- `YieldCurvePointIdentity::canonical_key()` 是身份的稳定文本投影：字段顺序固定，
  `vintage` 缺失渲染为 `-`（**保留维度**，不得整段省略）；同一身份必须得到同一键，
  不同身份必须得到不同键。
- `vintage` 无官方 vintage 面时 MUST 为 `None`，MUST NOT 伪造。

## 4. 官方与派生二分标准

- `YieldCurvePointOrigin` 二分：`Official`（上游直接给出）/ `Derived`（由其它曲线点计算得到）。
- **派生点必须完整**：`origin = Derived` 的点 MUST 声明至少一个输入身份
  （`derived_from` 为 `Some(非空)`）；缺失或空数组即「不完整派生」，
  MUST 被拒绝为 `SemanticallyRejected`（对应负向样本
  `negative_incomplete_derived.json` 的语义）。
- **官方点不得声明派生输入**：`origin = Official` 且 `derived_from` 为 `Some` 时为语义矛盾，
  MUST 被拒绝。
- 取值模型 `YieldCurveRate::{Present(f64), Missing(YieldCurveMissingReason)}`：缺失必须以具名
  原因表达（`SourceBlank` / `NotPublishedYet` / `NotApplicable`），MUST NOT 静默转 0；
  `Present` 不得为 `NaN` 或无穷。
- 校验在**两条路径**上一致：`YieldCurvePoint::new`（构造期）与 `validate_curve_point`（校验期）。

## 5. 曲线批与解析标准

- `YieldCurveBatch` 的 `points` **私有**：唯一入口是 `YieldCurveBatch::new`，
  它保证批内 `canonical_key` **唯一**；重复身份 MUST 被拒绝（不得静默去重、不得后写覆盖）。
- 空批**合法**（`len() == 0`、`is_empty() == true`）；含重复身份的批非法。
- `validate_curve_batch(&[YieldCurvePoint])` 接收**候选切片**（不要求先构造批），
  逐点校验**全部**元素（不得只看第一条）并做唯一性检查；空切片合法。
- `YieldCurveBatch` 携带批级 `frequency` 与 `unit`（保留源侧单位，不做换算）。
- **离线解析** `parse_yield_curve_batch`：输入为 JSON 字符串，MUST NOT 接受 URL、客户端或凭据；
  未知字段、缺字段、类型不符一律**原子失败**；令牌（`frequency` / `unit` / `origin` /
  `missing_reason` / `curve_kind` / `maturity`）未知即拒绝；`rate_percent` 与 `missing_reason`
  不得同时给出（取值歧义）。
- `parse_yield_curve_batch` **要求**顶层 `"_synthetic": true`：未标注来源的 JSON MUST 被拒绝，
  以免把来源不明的数据当成源事实；`kind` 须为 `kernel_fixture`。
- 错误消息不回显原始内容。

## 6. 路由接收端与 provider 边界

- kernel 是曲线点的**接收端**，不是拉取端。已声明的路由来源（`ROUTE_SOURCES`）共 4 个：
  `treasuryx:DS06`、`treasuryx:DS07`、`ecbx:YC-dataflow`、`ukx:S07`。
- `receive_routed_batch` 只做**身份与批校验**，MUST NOT 拉取、认证、缓存或再分发；
  拒绝消息带来源标签，错误**分类保持不变**。
- 曲线构建（bootstrapping / 插值 / 拟合）、利差、z-score 等派生计算**不在本域**，归 analytics。
- 写入主权：曲线点的权威写入方是 `yieldx`；各 provider 侧拒绝并路由（本域不实现其守卫）。
- 32 个 provider 的授权为 `0/32`：本域 MUST NOT 主张、也 MUST NOT 代批任何 provider 授权。

## 7. publication 语义与合成夹具声明

- `yield_curve_publication_semantics()` 恒返回 `(TimePrecision::Date, AvailabilityEvidence::Inferred,
  PitEligibility::NotEligible)`；`is_formal_pit_eligible()` 恒为 `false`。
- MUST NOT 补造 `00:00 UTC` 之类时刻把 `Date` 伪装成 `Instant`；MUST NOT 静默升格为正式 PIT。
- `tests/fixtures/` 下的**全部**夹具为特性 005 自拟的**合成样本**，**不是真实源数据**，
  **不构成任何证据**；每个文件都带顶层 `"_synthetic": true` 与 `_note` 声明。
- 夹具文件名与角色对齐清单 §2.0 的登记（官方 par 样本 / 含 derived 利差 / 负向 incomplete
  derived）；MUST NOT 编造清单未提到的字段或统计码。
- MUST NOT 把合成夹具的数值表述为「实测」「核验 PASS」或任何证据等级；
  夹具也不填充 32 个 provider 的授权，不解除 `NO-GO`。
